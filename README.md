# GRAIN ROOM

写真を、素材に。カラーと変形の写真実験室。

**[ブラウザで開く](https://synomare.github.io/grain-room/)**

66の加工と72の組合せレシピ。写真の色、線、密度、流れ、表面を変え、加工を重ねてPNGへ書き出せます。写真は端末内で処理され、サーバーへアップロードされません。

## 使い方

- 右上：写真を開く、原画と比較、表示倍率、PNG書き出し、JSONレシピの保存・読込。
- 右中央：加工の数値調整、カラー／白黒、彩度、重ねがけ。
- 下中央：加工を検索、組合せレシピ、変奏。
- ホイールで拡大縮小、拡大後はドラッグで移動。ダブルクリックで全体表示。

写真と作業は自動保存されません。再読み込み前にPNGやJSONを保存してください。JSONには写真は含まれません。処理中は直前の高精細画像を保持します。大きい写真や重い加工では処理に時間がかかります。

入力はJPEG／PNG／WebPなどブラウザ対応形式。HEIC／RAW／動画は対象外。PNGは元画像より拡大せず、最大長辺4096px。加工の内部計算解像度は方式ごとに異なります。スマートフォン実機の速度とSafari固有の挙動は引き続き検証対象です。

## 開発

Node.js 22.12以降を使用します。

```sh
npm ci
npm run dev
npm test
npm run build
npm run check:release
npm run preview
```

開発は `/`、製品プレビューと公開版は `/grain-room/` を使います。製品ビルドにはローカル専用フォントを含めません。ローカルで所持するReplicaを使う場合だけ、Git管理外の `.env.local` に `GRAIN_REPLICA_FONT` を設定します。

`main`へのpushでGitHub Actionsがテスト・ビルド・配信・配信ファイルのハッシュ照合を実行します。`build-info.json` にエンジン版・commit・配信ファイルのSHA-256を記録します。

## 研究と素材

各加工の「この加工の研究背景」から一次資料と実装範囲を確認できます。論文の一部を独立実装・翻案した視覚表現であり、研究全体の再現や実測物理量のシミュレーターではありません。
